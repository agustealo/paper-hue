# Paper Hue feature roadmap

## Slice A — Control center

- Appearance → Paper Hue read-only status dashboard.
- Central configuration/status service.
- Direct links to canonical WordPress management screens.
- No duplicated option storage.

## Slice B — Hero Slider

- Source selection: category, latest posts, sticky posts, manual selection.
- Slide count, ordering, excerpt, CTA, controls, autoplay, pause behavior, mobile behavior.
- Accessibility and reduced-motion behavior.
- Preserve the classic Paper Hue visual treatment by default.

## Slice C — Featured Story

- Keep WordPress sticky posts as the underlying native mechanism.
- Expose a first-class Featured Story concept in Paper Hue.
- Support latest sticky or explicit selection without creating a custom content type.
- Add metadata, excerpt, CTA, and fallback-image controls.

## Slice D — Recent Articles

- Source/category controls.
- Exclusions and featured-story deduplication.
- Count and pagination.
- Small set of Paper Hue-native layout variants.
- Metadata and excerpt controls.

## Slice E — Real product proof

- Run the exact release candidate on WordPress.
- Capture governed desktop/mobile screenshots from the real app/theme.
- Update README, documentation, and release presentation only from those captures.
